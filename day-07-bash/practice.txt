## EXERCISE 6: FILE READABILITY

Condition:

```bash
if [ -r config.txt ]
then
    echo "config.txt is readable"
else
    echo "config.txt is not readable"
fi
```

Questions:

1. What does `-r` check?
2. What happens if the file is readable?
3. What happens if the file is not readable?

## EXERCISE 7: COMBINE CONDITIONS

Condition:

```bash
if [ -f config.txt ] && [ -r config.txt ]
then
    echo "Config file exists and is readable"
else
    echo "Config file is missing or not readable"
fi
```

Remember:

- `&&` means both conditions must be true.
- `||` means at least one condition must be true.
