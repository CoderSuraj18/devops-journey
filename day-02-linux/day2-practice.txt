Linux Filesystem Hierarchy:

The Linux filesystem is a hierarchical structure that starts
from the root directory (/).


Absolute Path:

A complete path that starts from the root directory (/)
and identifies the exact location of a file or directory.


Relative Path:

A path that identifies a file or directory relative to the
current working directory.


Root Directory (/):

The top-level directory in Linux. All other directories and
files exist under it.


Home Directory (~):

The personal directory of a Linux user where their personal
files and settings are normally stored.


Parent Directory (..):

Represents the directory one level above the current directory.


Current Directory (.):

Represents the directory you are currently working in.


Files:

Objects used to store data such as text, configuration,
scripts, or application information.


Directories:

Containers used to organize files and other directories.


cat:

A command used to display the contents of a file.


cd:

A command used to change the current working directory.


pwd:

A command used to display the current working directory.


ls:

A command used to list files and directories.
